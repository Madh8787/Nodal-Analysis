# Petroleum Production Engineering Project: IPR–VLP Analysis

## Project Overview
This project models and compares **Inflow Performance Relationship (IPR)** and **Vertical Lift Performance (VLP)** for two wells.  
The analysis determines the **operating point (Q, Pwf)** where reservoir inflow matches wellbore outflow.

## Features
- Implements **Darcy IPR** and **Vogel IPR** correlations.
- Calculates **Vertical Lift Performance (VLP)** using hydrostatic and frictional gradients.
- Plots **IPR–VLP curves** and identifies the **operating point**.

## Results
- Graphs compare **Darcy IPR, Vogel IPR, and VLP** for both wells.
- Operating points are calculated automatically:
  - **Well A**: Q ≈ 4159.1 STB/day, Pwf ≈ 1894.8 psi  
  - **Well B**: Q ≈ 2657.5 STB/day, Pwf ≈ 1323.6 psi
